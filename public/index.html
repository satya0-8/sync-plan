Connect Claude to SyncPlan via MCP

You can connect your local Claude Desktop to SyncPlan in 30 seconds using Model Context Protocol:

1. Open Claude Desktop Config

On macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
On Windows: %APPDATA%\Claude\claude_desktop_config.json

2. Paste this MCP Configuration
{
  "mcpServers": {
    "syncplan": {
      "command": "node",
      "args": ["/path/to/syncplan/mcp-server.js"],
      "env": {
        "SYNCPLAN_API_URL": "http://localhost:3000"
      }
    }
  }
}
3. Or use Remote MCP HTTP / SSE Endpoint
http://localhost:3000/sse
4. Restart Claude and Test

In Claude, type: "Here are the kickoff notes for FinTech Corp. Create an onboarding plan with NetSuite integration and team training." Claude will call create_action_plan and give you a live URL!
